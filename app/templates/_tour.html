{# A click-through overlay of short text boxes. Needs: tour_steps -- [{title, text, target?}] where target is an optional CSS selector to spotlight -- and tour_key. tour_key set: shows automatically once per browser, then remembers it (localStorage). The key carries the firm id, so on a shared classroom Chromebook the NEXT team still gets the tour. tour_key none: shows automatically EVERY time the page loads, no memory. tour_autostart (optional, default true): false means never open by itself -- sandbox passes current_round == 1, so each practice game opens it on its Round 1 decision screen, even after logging out and back in, and not in later rounds. Either way window.startTour() replays it on demand (the "Rewatch the Page Intro" button). If storage is blocked (private window) a keyed tour just shows each visit -- never an error. Without JS nothing renders. #}
